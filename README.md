# 🎯 Rastreador de Metas Diárias (Daily Goals Tracker)

Este repositório consolida ferramentas e scripts desenvolvidos para o acompanhamento e gestão de metas diárias. O projeto demonstra a aplicação prática de lógicas de rastreamento de hábitos e objetivos do dia a dia, construídas em diferentes linguagens de programação.

## 📁 Estrutura do Monorepo

| Diretório | Linguagem | Descrição |
| :--- | :---: | :--- |
| **`python_meta_diaria/`** | Python | Lógica e script focados no registo, cálculo e acompanhamento das metas diárias via terminal. |
| **`javascript_meta_diaria/`** | JavaScript | Implementação em JavaScript para o controlo e gestão interativa de tarefas e objetivos diários. |

## 🛠️ Tecnologias Utilizadas

* **Python 3**
* **JavaScript**
